# MOS UGREEN LEDs

mos-ugreen-leds provides a **MOS plugin** for controlling the front panel LEDs
(power, network and disk slots) of UGREEN DX/DXP NAS devices.

---

## Overview

This repository contains the MOS plugin implementation, optional helper functions, configuration files (such as settings.json), required to run
the UGREEN LEDs functionality within MOS.

---

## Build & Automation

This repository includes a **GitHub Actions workflow** used to build and package
the plugin for MOS.

The build process is fully automated and produces artifacts that can be
installed through the MOS Hub.
